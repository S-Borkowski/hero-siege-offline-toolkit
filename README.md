# Hero Siege Offline Toolkit

A collection of offline/single-player tools for Hero Siege.

This project is a central hub for my Hero Siege tools.  
It includes save editing, value scanning, loot assistance and Steam Deck utilities.

> These tools are intended for offline / single-player use only.

---

## Tools

### HS Save Editor
Edit character-related save values such as level, gold and professions.

Repository: https://github.com/falorfrozen-cmd/HSSaveEditor

---

### HS Value Scanner
Find and modify in-game values such as Magic Find, Movement Speed and stacked item counts.

Repository: https://github.com/falorfrozen-cmd/HS-ValueEditor

---

### HS Offline Loot Forge
A target-farming helper designed for offline Hero Siege gameplay.

Repository: https://github.com/falorfrozen-cmd/Hs-Offline-Loot-Forge

---

### HS Steam Deck Save Editor
A browser-based save editor designed for Steam Deck users.

Repository: https://github.com/falorfrozen-cmd/HSSaveEditor-SteamDeck-

---
